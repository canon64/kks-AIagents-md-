# デコンパイル手順ガイド

## Assembly-CSharp.dll とは

KoikatsuSunshineのゲームロジック（キャラ制御、表情、Hシーン処理等）が全部コンパイルされて入っているDLL。約384クラス、数十万行規模。ゲームのクラスを触りたければここを見るしかない。

## ilspycmd の基本オプション

```bash
# クラス名を探す
ilspycmd -l "type" "F:/kks/CharaStudio_Data/Managed/Assembly-CSharp.dll" | grep -i "キーワード"

# クラスをデコンパイルしてファイルに保存
ilspycmd -t "完全修飾クラス名" "F:/kks/CharaStudio_Data/Managed/Assembly-CSharp.dll" > _decomp/ClassName.cs
```

## 調査の流れ

1. **何を調べたいか決める**（例：表情制御）
2. **grep でクラス名を探す**（全体を出力しない。キーワードで絞る）
3. **怪しいクラスだけデコンパイル**して `_decomp/` に保存
4. **コードを読んで必要なメソッドを特定**する
5. **調査結果を `analysis/` に残す**（次のセッションで再調査しないため）

## トークンコストの考え方

- 全クラスをデコンパイルすると100万トークン前後になり、コンテキストに入らない
- AIは「どこが重要か」をコードだけから判断するのは苦手
- **必要なクラスだけを都度デコンパイルする**のが正しいやり方
- 「このクラスのこのメソッドが重要、なぜなら〇〇」という人間の判断を `analysis/` に残しておくことで、次回の無駄な再調査を防ぐ

## 注意

- デコンパイル結果は完全に元通りではない（変数名が失われたりする）
- クラス構造・メソッドシグネチャ・ロジックは十分読める
- `ilspycmd -l` で一覧を出す際も出力が大きくなるので `grep` で絞ること
