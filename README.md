# kks-AIagents-md

KoikatsuSunshine (KKS) の BepInEx プラグイン開発で使っている AI エージェント向け指示ファイルの構成をそのまま公開したもの。

Claude Code を使って開発しているので、`CLAUDE.md` が中心になっているが、考え方自体は他のエージェントにも応用できると思う。
Codexなど他のAIツールを使うなら、`CLAUDE.md` を `AGENTS.md` に変更して使ってくれればいいと思う。

---

## これは何か

AI に「何をすべきか」「どこを見るべきか」を伝えるための指示ファイル群。

プロジェクトが大きくなると、毎回同じ説明を繰り返すか、AI が推測で動いて余計なことをするかのどちらかになる。それを防ぐために作った。

- `CLAUDE.md` — 鉄則・作業ルール・ファイルマップ（AI が最初に読む）
- `docs/` — 開発ガイド（デコンパイル手順、ログ実装、Harmony パッチ等）
- `analysis/` — 調査ノートと、新規プラグイン作成前に確認するチェックリスト

---

## 構成の考え方

- `CLAUDE.md` は短く保つ。50行程度がいいと思う。詳細は `docs/` に分散させる
- 「どのファイルを見ればいいか」の索引を `CLAUDE.md` に書く
- 調査結果はファイルに残す。AI のコンテキストは消える

---

これは自分の環境・開発スタイルに合わせて作ったものであって、正解ではない。
